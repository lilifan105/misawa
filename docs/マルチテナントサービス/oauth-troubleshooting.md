# OAuth 2.0トラブルシューティングガイド

## よくあるエラーと対処法

### 1. `invalid_client`エラー

**原因**: client_secretが無効

**対処法**:
- client_secretが正しいか確認
- シークレットが再生成されていないか確認
- 環境変数が正しく設定されているか確認

### 2. `redirect_uri_mismatch`エラー

**原因**: リダイレクトURIが登録されたURIと一致しない

**対処法**:
- 認可リクエストのリダイレクトURIを確認
- 登録されたリダイレクトURIと完全に一致するか確認
- クエリパラメータやフラグメントが含まれていないか確認

### 3. `invalid_grant`エラー

**原因**: 認可コードが無効または期限切れ

**対処法**:
- 認可コードは5分で期限切れ
- 認可コードは1回のみ使用可能
- 新しい認可コードを取得

### 4. `invalid_request`エラー

**原因**: リクエストパラメータが不正

**対処法**:
- 必須パラメータがすべて含まれているか確認
- パラメータの形式が正しいか確認
- code_challenge_methodが`S256`であることを確認

## デバッグ方法

### ログの確認

1. **クライアント側のログ**:
   - リクエストパラメータ
   - レスポンスステータス
   - エラーメッセージ

2. **サーバー側のログ**:
   - CloudWatch Logsで確認
   - Lambda関数のログを確認

### ネットワークトレース

ブラウザの開発者ツールでネットワークトレースを確認：
- リクエストURL
- リクエストヘッダー
- レスポンスステータス
- レスポンスボディ
